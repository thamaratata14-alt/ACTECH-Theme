Plugin de personalização visual para **GLPI 11**, desenvolvido pela **ACTECH Soluções Tecnológicas**.

---

## Objetivo

O ACTECH Theme foi criado para fornecer uma identidade visual moderna ao GLPI sem alterar os arquivos originais do sistema.

Todo o desenvolvimento é baseado em boas práticas, permitindo futuras atualizações do GLPI sem perda das personalizações.

---

## Recursos

- Tela de login personalizada
- Fundo institucional
- Logo personalizada
- Rodapé institucional
- Botão personalizado
- Favicon
- Compatível com GLPI 11

---

## Requisitos

- GLPI 11.0.x
- PHP 8.2 ou superior
